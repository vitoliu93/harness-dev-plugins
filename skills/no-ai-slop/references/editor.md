# Edit / detect protocol

## Intake

- If no draft was provided, ask for it.
- If audience or format is unclear, ask where it will be published and for whom.
- If the goal is unclear, ask what the reader should think, feel, or do.

## Editing principles

- Preserve the writer's vocabulary, cadence, bluntness, humor, uncertainty, and
  useful digressions. Make the minimum effective edit.
- Keep the meaning. Never invent claims, examples, stats, sources, or opinions.
- Lead with the point only when setup adds nothing. Keep stories and asides that
  create context or character.
- Prefer concrete facts, active voice, direct verbs, and readable sentence
  structure. Do not flatten every paragraph into the same polished rhythm.
- Keep useful edge: strong opinions, fragments, profanity, and roughness can be
  voice rather than defects.
- Preserve structure unless it blocks comprehension. If reorganized, say why in
  `What changed`.

## Language to cut

Cut when they add no meaning:

- hype/jargon: delve, foster, leverage, utilize, facilitate, empower, streamline,
  robust, cutting-edge, paradigm shift, game changer, tapestry, realm, beacon,
  multifaceted, meticulous, intricate, paramount, transformative, elevate,
  embark, supercharge, harness, ever-evolving;
- empty adverbs: just, literally, honestly, simply, actually, truly,
  fundamentally, importantly, crucially, inherently, inevitably;
- throat-clearing: "it's worth noting", "at the end of the day", "when it comes
  to", "at its core", "in today's world", "the reality is", "in terms of",
  "going forward", "let's dive in".

Keep one only when it carries real uncertainty, emphasis, or the writer's voice.

## Patterns to flag or remove

- Binary contrast: "not X, but Y" when saying Y directly is clearer.
- Faux insight: "what most people miss" or "here's what nobody tells you".
- Colon reveal: noun phrase + dramatic lowercase reveal.
- Superficial analysis: trailing "highlighting / underscoring / showcasing".
- Importance puffery: "pivotal moment", "vital role", "stands as a testament".
- Weasel attribution: "experts agree / studies show" without a named source.
- Fake-strong verbs and synonym cycling where plain `is/has` or one repeated
  noun is clearer.
- Negative listing, dramatic fragments, robotic repeated sentence shapes,
  rhetorical setups, and self-answered questions.
- Fake-profound kickers and conclusion paragraphs that merely restate the text.
- Formatting slop: decorative emoji/headings/bold/bullets and habitual em dashes.

## Workflow

1. Read the full draft.
2. Internally identify its core point and 3–5 voice signals to preserve.
3. Detect request: quote each offending line, name the pattern, give a short fix;
   do not rewrite, score, or guess whether AI wrote it.
4. Edit request: make the minimum effective changes and check against `eval.md`
   when that file is present.
5. Return the full edited draft plus a short `What changed` section.
