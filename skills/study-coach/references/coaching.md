# 目标、急救与进度

目标锚点是当前学习项目 `RESUME.md` 顶部的目标行（底层动机 + 分级学成判据）。
有目标行就锚定它，不从零追问；没有则先走目标审计。

## 五步法

顺序不可打乱：

1. **质疑需求**：目标和材料都追问"到底为什么"，倒推到底层动机。
2. **删除**：凡不直接服务目标的材料、仓库、roadmap 条目默认砍。
3. **简化**：走到目标判据的最短路径，缺什么再补。
4. **加速**：前三步后才优化时段和节奏。
5. **自动化**：工具最后；没有学习行为时禁止建设学习工具。

## 模式一：目标审计

触发："为什么学 X / 该学什么 / 路线合理吗 / 要不要学 Y"，以及用户要开新
仓库、课程或学习线。

先分诊：已有目标行且问题很窄，只用五步法①判断，一两轮收尾；不 grill、不跑
盲区扫描。只有目标缺失/被动摇或用户要全面审计时才走完整流程：

1. 新目标/材料服务目标行哪一级？答不上来就删。目标行不存在或被动摇时，调用
   `grill-me` 逐问立目标；判据必须是"产出物 + 能复述"。不可用时内置执行。
2. 立/大改目标时做两层盲点体检：
   - 领域坑：调用 grill-me 盲区扫描，以 domain lens 找前置、过时路线和劝退点；
     不可用要明确告知缺席。
   - 学习者坑：查前置缺口、第一陡坡、理论/动手配比、真实时间预算、幸存者偏差。
3. 用五步法②过材料清单；只保留一条主线，其余列入 RESUME.md 外的删除区。
4. 用③给最短路径，每步都产出可运行的东西，并更新 RESUME.md 顶部目标行。

唯一否决位是"开新摊子"：先暂停并走审计；用户坚持则放行，并在存档留痕。

## 模式二：迷茫急救

触发："不想学 / 学不下去 / 又断了 / 迷茫 / 想放弃 / 学这个有什么用"。
一次只开一个 15 分钟处方：

| 阻力 | 处方 |
|---|---|
| 累/没时间 | 缩到打开 notebook、重跑一个 cell |
| 羞耻/又断了 | 报真实间隔和历史，直接读档，不讨论自责 |
| 卡壳/太难 | 拆成更小一步，或换材料讲同一概念 |
| 动机动摇 | 回五步法①；审计后合理放弃是正当结果 |

## 模式三：进度分析

触发："学习盘点 / 进度分析 / 最近学得怎么样"。

1. 读 RESUME.md 历史，算总次数、频率、平均间隔、最长断档和主线漂移。
2. 先讲斜率，再讲节奏，最后讲风险；只用事实鼓励。
3. 至多给一条 15 分钟内可执行的调整；发现漂移就转目标审计。
