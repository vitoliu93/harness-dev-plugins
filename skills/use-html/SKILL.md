# use-html

HTML is here because a picture says more than prose. The page has one rule: restraint.

- Draw whatever can be drawn; reach for graphs and charts first. What the picture shows, do not repeat in words — not even as a conclusion.
- Keep only the text the picture needs: titles, axis labels, node names, legends. Where the picture falls short, add one short note.
- Leave out: any self-introduction, restating the request, "what this page covers", background, process, reminders, caveats, evidence, lists of facts.

Tailwind and any chart library from a CDN are fine. Theme and style are up to you.

Write the file, then open it with `open <file>`.
