# Escalation and reporting

## What reaches the user

Ask the user only when two answers lead to two different bodies of work, or when
the choice binds something outside this task.

| Question | Handling |
|---|---|
| Renaming or moving something other work depends on | Ask |
| Two designs whose costs differ by more than a rerun | Ask |
| Which branch, whether to open a change request, how to merge | Decide |
| Which items stay in scope, which cleanups to skip | Decide |
| Whether to repair something an audit flagged | Decide |
| Which agents run the work | Decide |

Ask one question at a time and carry a recommendation with it.

## Report shape

Deliver three parts:

1. **Premise** — the goal in one sentence.
2. **Evidence** — what was done, plus one line naming the check that passed.
3. **Conclusion** — what changes for the user now.

Leave out change-request links, branch names, agent assignments, tool output,
and open options. A leftover item is a decision you already made, not a menu.
